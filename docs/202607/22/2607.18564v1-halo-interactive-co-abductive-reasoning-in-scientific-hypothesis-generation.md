## 摘要
科学发现至关重要但效率低下，主要原因是海量搜索空间中的假设生成阻碍了突破。尽管当前的人工智能系统有助于生成新的候选假设，但缺乏对推理过程的交互支持，用户难以将这些输出发展为有前景的假设，导致假设停留在表面。为解决此问题，我们提出协同溯因（co-abduction），一种用于科学假设生成中溯因推理的人机协作框架。为实现协同溯因，我们构建了HALO，一个用于药物发现分子假设生成的人机协作系统，实现了改进的候选聚类、策略识别和多策略合成。在涉及10位药物化学家的专家研究中，HALO显著促进了假设生成的溯因推理——高效的候选观察、系统的策略识别和连贯的多策略组合——并使参与者能够产生更高质量、更多样化的候选分子。

## Abstract
Scientific discovery is essential yet inefficient, primarily because generating hypotheses within a vast search space hinders breakthroughs. While current AI systems assist in generating new hypothesis candidates, they lack interactive support for the reasoning process by which users develop these outputs into promising hypotheses, resulting in surface-level hypotheses. To address this issue, we present co-abduction, a human-AI collaborative framework for abductive reasoning in scientific hypothesis generation. To operationalize co-abduction, we build HALO, a human-AI collaborative system for molecular hypothesis generation in drug discovery, enabling improved candidate clustering, strategy identification, and multi-strategy synthesis. In expert studies involving 10 medicinal chemists, HALO significantly facilitated abductive reasoning for hypothesis generation -- efficient candidate observation, systematic strategy identification, and coherent multi-strategy composition -- and enabled participants to produce higher-quality, more diverse candidate molecules.

## 1. 核心问题与研究动机

- **核心问题**：科学发现（尤其是药物发现中的分子假设生成）效率低下。主要瓶颈在于，研究人员需要在巨大的搜索空间中导航，并平衡多个相互冲突的优化目标，如药效、毒性、溶解性等。现有的AI系统虽然能生成大量候选分子，但缺乏对用户**推理过程**的交互式支持，导致用户无法有效利用AI输出，只能进行“表面化”的假设生成，未能解决根本的效率问题。
- **研究动机**：亟需设计一种新的AI系统，能够主动支持研究人员的**溯因推理**过程，帮助其从碎片化的观察中，系统地识别模式、整合策略，最终形成高质量的、有科学深度的假设。弥合AI生成与人类专家推理之间的鸿沟。

## 2. 方法论：核心思想与关键技术

- **核心思想**：提出**Co-abduction（协同溯因）**框架，将“溯因推理”这一逻辑过程形式化为一个**人机协作的迭代循环**，包含三个阶段：
    1.  **高效观察（Efficient Observation）**：人与AI共同生成分子候选，并根据其性质改善情况（哪些性质变好，哪些变差）进行聚类，快速理解优化景观。
    2.  **系统策略识别（Systematic Strategy Identification）**：AI分析每个聚类内部的分子，自动识别并解释哪些结构片段（R-基团）与特定性质的改善相关，为专家提供可解释的优化策略。
    3.  **连贯多策略合成（Coherent Multi-strategy Synthesis）**：AI跨聚类推荐组合策略（如将提升溶解度的策略与降低毒性的策略结合），用户以“乐高式”的方式点击应用这些策略，并在实时性质反馈中迭代优化分子。
- **支撑系统HALO**：
    -   **MolCluster**：负责第一步，通过交互式聚类图，让用户按任意性质组合切换和筛选分子簇。
    -   **MolStrategy**：负责第二步，对每个聚类进行深度分析，包括核心骨架检测、R-基团库构建、LLM生成的聚类总结和具体优化建议。
    -   **MolSynthesis**：负责第三步，展示来自同一簇和不同簇的优化策略，用户点击即可将策略应用到分子编辑器，并实时更新性质评分。
- **关键技术细节**：
    1.  **分子生成**：采用了对 `Llama 3.1 8B-Instruct` 模型在 `C-MuMoInstruct` 数据集上微调的模型，用于根据起始分子和优化目标生成新分子。
    2.  **性质评估**：使用 `ADMET-AI` 和 `Therapeutic Data Commons` 工具为生成的分子计算药理性质评分。
    3.  **模式识别与分析**：通过 `RDKit` 进行分子结构分析（最大公共子结构MCS、R-基团分解、化学类型分析），识别核心骨架、频率最高的R-基团等。
    4.  **策略生成**：使用 `Gemini 3 Flash` 语言模型，基于前一步分析的结构化信息生成自然语言的策略解释和具体的分子修改建议。
    5.  **算法流程**：无传统数学公式，整个过程是一个端到端的流水线：任务输入 -> LLM分子生成 -> 候选聚类 -> 聚类分析（骨架、R-基团） -> LLM策略生成 -> 用户交互式合成策略 -> 最终分子输出。

## 3. 实验设计

    -   **任务A**：优化 `PlogP`、`hERG`、`CARC`（致癌性）、`LIVER`（肝毒性）。
    -   **任务B**：优化 `PlogP`、`QED`、`DRD2`、`LIVER`。
- **基准（Baseline）**：一个不包含HALO三个核心功能（`MolCluster`， `MolStrategy`， `MolSynthesis`）的对照系统。该系统保留了HALO的基础功能，如AI分子生成、手动编辑、性质展示和一个独立的LLM对话窗口（用于用户自行输入提示词），模拟当前常见的AI辅助实践。

## 6. 主要结论与发现

1.  **协同溯因框架有效**：HALO在**高效观察**、**系统策略识别**、**连贯多策略合成**三个方面，均获得用户显著更高的7点Likert评分（p < 0.05 或 p < 0.01），且**总体满意度**也更高。用户普遍认为HALO的流程与他们的自然思维模式相符。
2.  **生成结果质量更高**：使用HALO时，用户提交的分子质量（平均能同时改善更多性质）显著优于Baseline（HALO: 3.16 vs. Baseline: 2.25, p < 0.01）。
3.  **生成结果多样性更高**：使用HALO产生的分子多样性也更高（HALO: 46.07% vs. Baseline: 58.27%的平均Tanimoto相似度，p < 0.01。**注意**：数值越低代表相似度越低，即多样性越高）。
4.  **“溯因飞跃”现象**：用户在使用HALO时平均经历1.8次“Aha!”时刻。
    -   **飞跃前**：AI是**催化剂**，用户广泛探索和测试策略。
    -   **飞跃后**：用户**主动性增强，对AI的依赖急剧下降**，更愿意手动编辑来细化自己的想法。这表明AI在用户获得新洞见后，角色应从“引导者”转变为“支持者”。

## 8. 不足与局限

- **缺乏湿实验验证**：这是最根本的局限。所有“质量”和“成功”的评估都基于计算模型预测（`ADMET-AI` 等），而非真实的生化实验。一个计算上“更优”的分子在实际中可能无法合成或毒性更高。作者承认这一点，但这是目前阶段科研的普遍难题，不构成对该方法本身的否定。
- **有限的实验广度和样本**：单一领域（药物发现）、单个任务场景、10位专家、30分钟时长，严重限制了结论的**外部效度**和**泛化能力**。该框架是否适用于材料科学、蛋白质设计等其他领域，以及在更长的时间跨度下效果如何，尚待验证。
- **潜在的认知负担**：用户反馈在优化方向明确后，HALO的策略建议过多，反而带来了认知负担。这表明系统在“多样性探索”和“聚焦性优化”之间的平衡上，还有进一步优化的空间。
- **样本与实验时长**：作者已明确指出这两个局限。10名专家的样本量在统计检验中的功效有限，且30分钟的实验时长远短于真实研发周期，可能无法完全反映系统在长期工作流中的优势和劣势。
