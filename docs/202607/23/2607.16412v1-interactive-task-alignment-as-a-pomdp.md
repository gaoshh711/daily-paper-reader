## 摘要
当前语言模型的基准测试主要评估其在完全指定任务上的执行能力。然而，真实用户任务往往是模糊的。用户带着不完整、探索性甚至不一致的目标而来，需要助手在执行任务之前首先确定预期任务。我们将此问题研究为任务对齐：即与用户就其预期任务达成一致的能力。我们引入了一个通用框架，将指定任务转换为欠指定交互，形式化为一个部分可观测马尔可夫决策过程（POMDP），其中模型必须从部分且不断演变的用户意图中推断潜在任务。我们通过人工用户研究事后验证了我们的用户模拟器。在购物、编程和专业工作场景中，我们发现，尽管模型在任务指定后通常表现良好，但它们在任务对齐上仍然存在困难：当前模型过早行动、交互效率低下，且未能解决模糊需求。在模糊情况下，模型平均只有22-32%的时间能恢复用户的预期任务。在相同环境下的人工研究中，人类达到48%，优于所有评估的模型。我们表明，通过监督微调和强化学习进行后训练可以改善任务对齐，但模型在通过交互解决不确定性方面仍落后于人类。总之，我们的结果表明，当前模型仍然缺乏实现可靠代理所需的关键交互能力。

## Abstract
Current benchmarks for language models primarily evaluate execution on fully specified tasks. However, real user tasks are often ambiguous. Users arrive with incomplete, exploratory, or even inconsistent goals, requiring the assistant to first determine the intended task before carrying it out. We study this problem as task alignment: the ability to align with a user on their intended task. We introduce a general framework for converting specified tasks into underspecified interactions, formalized as a POMDP in which the model must infer a latent task from partial and evolving user intent. We validate our user simulator post hoc with a human user study. Across shopping, coding, and professional work settings, we find that while models often perform well once the task is specified, models still struggle with task alignment: current models act prematurely, interact ineffectively, and fail to resolve ambiguous requests. Models on average recover the user's intended task only 22-32% of the time under ambiguity. In a human study in the same setting, humans reach 48%, outperforming all evaluated models. We show that post-training with supervised fine-tuning and reinforcement learning improves task alignment, but models still lag behind humans in resolving uncertainty through interaction. Together, our results suggest that current models still lack key interaction abilities required for reliable agency.

- **核心问题**：当前语言模型（LLM）主要在完全指定的任务上评估，但真实用户任务往往是模糊、不完整、探索性甚至不一致的。在这种情境下，模型的瓶颈从“如何执行已知任务”转变为“如何确定用户实际意图的任务”。论文将此问题定义为**任务对齐（task alignment）**，即助手与用户就预期任务达成共识的能力。
- **整体含义**：任务对齐是任务执行的前提条件，即使模型能完美执行指定任务，若无法正确推断用户意图，也会失败。论文指出，当前模型缺乏在不确定性下进行有效交互和推断的能力，这阻碍了它们成为可靠的自主代理。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：将任务对齐形式化为一个**部分可观测马尔可夫决策过程（POMDP）**。从助手视角，环境状态包括隐藏的真实任务规范 x*、用户当前意图状态 i_t 和对话历史 h_t；助手只能观测到对话历史，必须通过交互逐步推断隐藏任务，并决定何时承诺执行任务。
- **关键技术细节**：
  - **状态与观测**：状态 s_t = (x*, i_t, h_t)，x* 固定，i_t 和 h_t 随时间演变。观测 o_t = h_t。
  - **动作**：助手动作 a_t = (响应文本 m_t^a, 终止信号 e_t ∈ {0,1}, 候选排序 ρ_t)。ρ_t 在独立线程中每轮获取，用于评估助手信念。
  - **转移**：x* 固定；用户模拟器基于意图和对话产生响应 m_t^u，并通过意图演化器 E 更新意图状态 i_{t+1}。意图演化器有特权访问 x*，逐步暴露细节。
  - **评估指标**：
    - **任务恢复**：CommitAcc@1（终止时排名第一为正确）、CommitRank（归一化排名）、CommitReward（权衡正确性与交互成本）。
    - **不确定性消解**：信念熵 H_t、总信息增益 TotalIG = H_0 - H_{T*}。通过四象限分类（正确/错误 × 自信/不确定）分析模型行为。
  - **用户模拟器**：基于 LLM 实现，初始意图从抽象到具体三个层级（abstract / moderate / concrete），由 LM 从 x* 生成。候选集 C 包含 x* 和 14 个扰动项（购物场景直接使用真实搜索结果，编程和职业任务由 LM 生成扰动）。

### 6. 论文的主要结论与发现

- **任务对齐困难**：在抽象意图下，模型平均 CommitAcc@1 仅为 22%-32%（Shopping 22.0%，GDPVal 27.6%，Terminal-Bench 32.2%），远低于任务执行能力（Shopping NDCG 81-88%）。
- **人类显著优于所有模型**：人类在购物具体意图层级上 CommitAcc@1 达 48%，最高模型（GLM-5.1）仅 36.9%。

- **任务对齐是可分离且跨域一致的维度**：能力-对齐方差分解显示约 39% 的对齐方差与能力正交；跨任务排名一致性 Kendall W=0.62（残差化后 0.58），表明对齐是稳定的模型属性。
- **后训练（SFT 和 RL）可改善对齐**：Qwen3.5-9B 的 SFT 和 RL 都提升了 CommitReward（约 2.5 倍），减少了“自信错误”的比率，增加了“诚实不确定”的比率，但仍落后于人类表现。
- **模型过早承诺**：GPT-5.4 系列在 1-3 轮内即终止对话，无法有效获取信息。

### 7. 优点：方法或实验设计上的亮点

- **形式化清晰**：将任务对齐严格建模为 POMDP，分离了任务发现与任务执行，提供了可泛化的评估框架。
- **多维度评估指标**：同时测量任务恢复（正确率、排名）和不确定性消解（熵、信息增益），避免仅凭正确率误判模型行为。
- **人类与模拟器双验证**：通过人类助理实验直接比较模型与人类；通过用户模拟器验证，证明模拟器能产生与真实人类相似的行为。
- **能力-对齐的可分离分析**：利用购物场景能力饱和的特点，证明对齐是独立于能力的维度，并通过方差分解和跨域一致性加强这一结论。
- **后训练研究**：展示了 SFT 和 RL 对任务对齐的影响，并分析了信念四象限的变化。

### 8. 不足与局限

- **训练范围局限**：仅对单一骨干（Qwen3.5-9B）在单一任务（购物）上进行训练，未评估向更大模型或其他任务（GDPVal/Terminal-Bench）的迁移性。

- **未考虑下游执行**：论文仅评估任务对齐阶段，不涉及任务执行阶段，无法评估对齐失败如何影响最终结果。
- **计算资源限制**：RL 训练仅 200 个提示，可能无法充分探索策略空间。
