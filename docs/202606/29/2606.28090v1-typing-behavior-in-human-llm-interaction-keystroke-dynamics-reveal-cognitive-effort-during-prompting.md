## 摘要
随着大语言模型（LLM）日益融入日常生活，理解用户如何与这些系统交互对于有效的人机协作至关重要。本研究探索了击键动态作为人机交互中用户心理努力和感知输出有用性的行为测量指标。我们通过一项用户研究（N=36）考察任务难度（简单与困难）和设备类型（桌面与移动）如何影响交互过程中的打字行为和工作负荷（NASA-TLX）。结果表明，困难任务导致显著更多的击键、更慢的打字速度、更长的暂停时间以及更高的自报工作负荷。设备类型的影响较弱，移动设备使用略微减少了输入长度和打字速度。虽然击键捕捉到了认知努力的差异，但它们未能预测感知到的LLM输出有用性。这些发现凸显了击键动态作为LLM提示过程中认知努力实时指标的潜力，同时也显示了它们在捕捉感知协作成功方面的局限性。

## Abstract
As Large Language Models (LLMs) become increasingly integrated into daily routines, understanding how users interact with these systems is crucial for effective human-AI collaboration. This work investigates keystroke dynamics as a behavioral measure of user mental effort and perceived output usefulness in human-LLM interaction. We conducted a user study (N = 36) to examine how task difficulty (easy vs. hard) and device type (desktop vs. mobile) influence typing behavior and workload (NASA-TLX) during interactions. Our results indicate that hard tasks led to significantly more keystrokes, slower typing, increased pauses, and higher self-reported workload. Device type had weaker effects, with mobile use slightly reducing input length and typing speed. While keystrokes captured differences in cognitive effort, they did not predict perceived LLM output usefulness. These findings highlight the potential of keystroke dynamics as real-time indicators of cognitive effort during LLM prompting, while also showing their limitations in capturing perceived collaboration success.

## 6. 主要结论与发现
- **任务难度效应显著**：困难任务导致更长的提示文本（+16.38 词）、更多击键（+127.89 次）、更多暂停（+6.27 次）、更慢打字（IKI 增加 46.93 ms），以及更高的 NASA-TLX 心理需求。击键指标成功捕获了认知努力。
- **设备类型效应较弱**：移动设备打字速度更慢（IKI 高 83.93 ms），但击键数、词数、暂停数的主效应不显著。交互效应显示移动设备上困难任务的击键增量减小（β=-88.41），提示输入约束限制了文本量。
- **退格行为不受影响**：退格使用在所有条件下无显著差异，表明编辑习惯相对稳定。
- **击键不能预测感知有用性**：LMM、PCR、随机森林模型均未发现击键指标与用户对 LLM 输出有用性评分之间的显著关联（R²≈0.01），说明行为指标反映的是努力程度而非协作成功。
- **用户体验差异**：困难任务下用户报告更低有用性、更高难度、更低信心，印证了“任务复杂性极化”现象（AI 未有效简化困难任务）。

## 7. 优点
- **创新性**：首次系统将击键动态应用于人-LLM 交互场景，拓展了传统击键研究（写作、编程）到动态对话协作领域。
- **方法严谨**：
  - 使用线性混合效应模型处理嵌套数据（用户、顺序、提示），控制个体差异。
  - 事前功率分析保证样本量合理。
  - 实验控制周密（禁用影响打字的辅助功能、任务难度基于 LLM 真实弱点设计）。
- **实用性**：击键采集无额外设备，易部署，为自适应 AI 系统提供可行方向（如根据认知负荷调整提示风格或模型选择）。
- **结果透明**：报告了非显著结果（感知有用性预测失效），避免发表偏差。

## 8. 不足与局限
- **实验覆盖有限**：仅使用一种任务（膳食计划）和一个 LLM（Llama 3.2 3B），结果泛化性存疑。不同任务或更强大模型可能改变击键模式。
- **参与者同质**：均为年轻大学生，高频 LLM 用户，缺乏对老年、低技术素养人群的代表性。
- **数据采集限制**：仅记录键按下事件，未记录键释放时间，无法计算停留时间（dwell time）和飞行时间（flight time），削弱了时序分析深度。
- **未考虑语义内容**：仅分析行为指标，忽略 prompt 的词汇多样性、情感等语义特征，可能遗漏与感知有用性相关的信息。
- **生态效度**：实验室环境下禁用复制粘贴、自动更正，模拟真实使用但降低了自然度；本地小模型响应质量可能与企业级 API 不同。
- **隐私风险提及**：击键动态可作为生物特征，论文虽建议边缘计算，但实际部署需额外防护。
