## 摘要
语言智能体越来越多地被部署在积累的多模态信息上，然而现有的基准测试假设的是人类-人类的形式，具有稀疏的视觉和直接的内容，既不评估对真实多模态文件交互的推理，也不评估对隐藏用户信息的解读。因此，我们引入了M$^3$Exam，一个基于真实用户-智能体交互的以查询为中心的多模态对话记忆基准测试，具有跨模态基础推理和隐式信息推断的多维度评估。对MLLMs和记忆系统的基准测试揭示了跨模态基础推理、跨会话推理以及积累多模态上下文的效率成本方面持续存在的差距。我们进一步提出了M$^3$Proctor，一种多模态记忆方法，它检测查询模态偏见，并仅在需要时消耗原始视觉源，将准确率提高13%，同时将索引构建时间和检索到的令牌减少超过70%。

## Abstract
Language agents are increasingly deployed over accumulating multimodal information, yet existing benchmarks assume a human-human form with sparse visuals and straightforward content, evaluating neither reasoning over authentic multimodal file interaction nor the interpretation of concealed user information. We therefore introduce M$^3$Exam, a query-centric multimodal conversational memory benchmark built on realistic user-agent interaction, with multi-dimensional evaluation spanning cross-modal grounding and implicit information inference. Benchmarking MLLMs and memory systems reveals persistent gaps in cross-modal grounding, cross session reasoning, and the efficiency cost of accumulating multimodal context. We further propose M$^3$Proctor, a multimodal memory method that detects query modality bias and consumes raw visual sources only on demand, improving accuracy by 13% while cutting index-construction time and retrieved tokens by over 70%.

## 2. 方法论：核心思想、关键技术细节

### 2.1 M$^3$Exam 基准构建

- **核心思想**：以查询为中心（query-centric）的多模态对话记忆基准，包含 239 个多会话对话（15 个人物场景，共 3025 轮，1799 个多模态文件），配对 5150 个评估问题。问题分为 8 类，覆盖记忆（单会话检索、文件管理、事实判断）、推理（多会话、多模态推理、时间推理）和解释（隐含推理、主题推理）。
- **构建流程**：
  1. **源输入**：从 (Persona, Core Event, File Pool) 三元组出发，人物传记和核心事件驱动生成。
  2. **时间线生成**：LLM 生成按时间排序的核心事件线（含事件描述、用户查询、时间、关键词），并穿插干扰事件（distractors），经过 LLM 自我检查和人工核查。
  3. **多轮对话合成**：使用事件滑动窗口，用户模拟器和助手模拟器基于当前事件和累积记忆（通过轮次摘要）生成对话，最后进行分块和跨块质量控制。
  4. **问题库合成**：从最终数据集中采样上下文窗口，提示 LLM 生成 8 类问题（SS, MS, TR, MR, FM, TH, II, FJ），每个问题附带支持事实轮次、有序答案列表（渐进粗略替代），经过验证确保可回答。

### 2.2 M$^3$Proctor 方法

- **核心思想**：模态感知的记忆方法。利用查询的模态偏好（modality bias）按需消费原始视觉源，避免全量注入图像导致令牌浪费和证据淹没。
- **关键技术细节**：
  1. **多模态索引构建**：将原始模态投影为可搜索的文本代理（图像：标题；图表：数值转录；文档页面：摘要+文字层），并附加模态标签 (I 图像, P 文档, C 图表)。同时为每个会话附加紧凑的会话摘要分块，保留跨会话信号。
  2. **模态感知推理**：
     - **偏见检测与偏置感知重排序**：用 LLM 检测查询的模态偏好向量 b(q) (二进制，表示是否需要 I/P/C)。使用偏置修正的相似度得分 s(q,c) = cos(q,c) + Σ λ_m * b_m(q) * I_m(c) 重新排序候选分块，λ_P > λ_I > λ_C，并加入多样性约束（覆盖会话摘要、跨越多个会话）。
     - **成本感知模态级联**：第一阶段仅用文本代理（标题、转录等）回答查询，通过置信度测试 Φ 决定是否升级。升级触发条件：文本答案不可靠（u(â1)=1）或模态偏好未被满足（β(q)=1）。第二阶段根据融合模态证据得分 e_m(q) 有选择地附加原始模态源，得分公式融合检索分块比例、检测到的偏置和表面词汇线索，仅在证据超过阈值时消耗原始源。

## 6. 主要结论与发现

1. **M$^3$Exam 具有挑战性**：最强的前沿 MLLM（GLM-5.1）总体分仅 0.549（满分 1），智能体记忆系统最高 0.484（M$^3$Proctor），远未饱和。
2. **跨模态和隐含意图问题是瓶颈**：系统在单会话推理上表现良好，但在多模态推理（MR）、文件管理（FM）、隐含推理（II）和主题推理（TH）上大幅下降。外部记忆系统能部分恢复这些能力。
3. **M$^3$Proctor 有效提升性能并降低成本**：在 Qwen-2.5-VL-7B 骨干上，M$^3$Proctor 总体分 0.484（比最佳现有记忆系统 MIRIX 的 0.456 提升 6%），在跨模态和隐含类型上领先。同时，索引构建时间仅 72 秒（比 MIRIX 的 43271 秒降低 600 倍），每查询令牌 4591（比 NGM 的 26888 降低 80%）。准确率提升 13%，令牌和索引时间减少超 70%。
4. **模态级联按需触发**：级联在视觉类型问题（FM 68%, MR 51%）上频繁触发，在文本类型问题（≤15%）上极少触发，且触发后显著提升答案质量（FM 提升 0.116, MR 提升 0.092），文本类型几乎不变。
5. **全上下文设置反而降低性能**：将完整对话历史送入模型（而非仅支持证据）会降低所有骨干的准确率，说明上下文干扰和检索压力不可忽视。

## 7. 优点

- **基准设计新颖全面**：首个同时评估多模态记忆、推理和隐含解释的基准，包含文档级工件（PDF）、图表、照片，以及多会话跨模态查询和未陈述意图推断。
- **合成数据+严格质量控制**：通过多阶段自动检查和人工审核确保数据质量，无真实用户隐私问题。
- **方法高效实用**：M$^3$Proctor 的模态感知级联在保持高准确率的同时大幅节省计算成本，易于集成到现有记忆系统中。
- **实验充分且公平**：多骨干验证、法官模型一致性检验、消融分析覆盖全面，结论可靠。
- **开源代码和数据**：促进未来研究。

## 8. 不足与局限

- **仅限单轮查询**：当前基准主要评估单轮 QA，真实世界交互常涉及多轮连续对话、意图演变和记忆迭代更新，未覆盖。
- **隐含解释能力有限**：M$^3$Proctor 在解释导向问题上仍表现不佳，更好的建模用户隐式状态和深层上下文解释待探索。
- **全合成数据**：尽管经过质量控制，仍可能存在生成偏差和无法完全代表真实用户行为。
- **未涉及动态记忆更新**：真实智能体需不断写入和合并新信息，基准未测试持续学习能力。
- **资源消耗不完整**：未报告模型训练成本，仅推理开销。
- **法官依赖**：虽然验证了法官一致性，但自动化评分仍可能对某些答案敏感。
