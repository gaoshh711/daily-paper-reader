## 摘要
在交互式环境中学习模拟人类用户，可以推动智能助手训练、个性化系统评估、社会科学研究等领域的发展。现有方法通常通过训练大型语言模型（LLM）来匹配单一的真实响应，要么最大化对数概率，要么使用相似性奖励。我们提出{Turing-RL}：一种基于图灵测试的强化学习方法，用于训练用户模拟器模型。{Turing-RL}使用判别式图灵奖励，由一个LLM评判器根据用户历史记录来评分生成的响应与真实用户难以区分的程度，用户模拟器LLM通过此类奖励学习产生与用户可能说的话无法区分的响应。在对话聊天和Reddit论坛讨论两个不同领域，我们发现{Turing-RL}在LLM和人类评估指标上均持续优于基线方法。我们的研究表明，优化不可区分性而非响应匹配，是学习用户模拟器的有效方法。

## Abstract
Learning to simulate human users in interactive settings could advance the training of agent assistants, evaluation of personalization systems, research in the social sciences, and more. Existing approaches generally do so by training a large language model (LLM) to match a single ground truth response, either by maximizing the log probability or by using a similarity reward. We instead propose {Turing-RL}: a Turing-Test-based reinforcement learning approach for training user simulator models. {Turing-RL} uses a discriminative Turing reward with an LLM judge to score how indistinguishable a generated response is from the real user's given the user's history, and the user simulator LLM learns to produce responses indistinguishable from what the user could have said with such rewards. Across two different domains--conversational chat and Reddit forum discussion--we find that {Turing-RL} consistently outperforms baseline methods on both LLM and human evaluation metrics. Our study suggests that optimizing for indistinguishability, rather than response matching, is effective for learning user simulators.

### 1. 核心问题与整体含义

- **研究背景与动机**：训练能够模拟特定人类用户的语言模型（用户模拟器）具有重要意义，可用于训练智能助手、评估个性化系统以及社会科学研究。然而，现有方法存在根本性局限：它们通常将用户模拟视为一个“响应匹配”任务，即训练LLM去**精确匹配**一个单一的、由真实用户产生的“黄金标准”响应。这通常通过最大化该黄金标准响应的对数概率或使用LLM评判器来计算生成响应与黄金标准响应的相似度来实现。
- **核心问题**：给定上下文，一个用户可能说出多种合理的话语。因此，要求模型精确复现“真实”的那一句话是不合理的，且会限制模型的泛化能力。论文的核心问题是：**如何训练一个用户模拟器，使其能生成与目标用户在风格、意图和内容上无法区分的响应，而不仅仅是机械地匹配一个特定的真实回答？**
- **整体含义**：论文提出，用户模拟器应该追求与真实用户的**不可区分性**，而非与某一具体回答的**内容匹配**。这直接关联到经典的“图灵测试”思想。

### 2. 提出的方法论：Turing-RL

- **核心思想**：提出一种名为Turing-RL的强化学习（RL）方法，其核心是使用一个基于LLM的**判别式图灵奖励**。该奖励信号评估的是模型生成的响应与真实用户历史记录和当前上下文的匹配度，即该响应在多大程度上看起来像是由**这位特定的真实用户**说出来的，而非仅仅是内容上相似。

- **关键技术细节**：
    1.  **图灵奖励定义**：训练一个LLM作为“图灵评判器”。对于每个训练样本，评判器会看到用户的全部历史信息（`h`）、当前对话上下文（`x`），以及两个候选响应：一个是真实用户的历史响应（`y*`），另一个是模拟器模型生成的响应（`y`）。评判器在1-7分的Likert量表上评分，分数越高代表生成的响应越像是真实用户说的。为避免奖励黑客，分数被截断并归一化到[0, 1]区间。
    2.  **RL训练流程**：模型（Qwen3-8B）首先在监督微调（SFT）阶段进行初始化。SFT阶段通过让模型学习“思维链”（Chain-of-Thought, CoT）推理轨迹来预热，使其能够解释用户为何会给出某个回答。之后，使用GRPO（Group Relative Policy Optimization）算法进行强化学习训练。对于每个输入，模型生成多个候选响应，然后使用图灵评判器计算每个响应的奖励，并基于组内归一化计算优势函数来更新模型参数。
    3.  **用户表示**：模型的输入`u`包含两部分：
        - 用户历史行为`h`：从该用户过去的会话中选取的一个固定段落，与当前预测目标不重叠。
        - 归纳人格`ρ`：使用一个辅助LLM（如GPT-5.4 nano）从用户历史`h`中归纳出一个结构化的人格描述（包括价值观、语气特点、表达风格、长度偏好和背景）。
    4.  **基础模型**：所有训练都基于Qwen3-8B模型，使用LoRA进行参数高效微调。

### 3. 实验设计

- **数据集与场景**：在两个结构差异显著的数据集上评估：
    - **PRISM（对话聊天）**：包含1,500名参与者与LLM助手多轮对话的数据集。筛选出1,288位至少有6段对话的用户。
    - **ConvoKit（Reddit论坛讨论）**：Reddit子论坛的讨论文本。筛选出1,282位至少在8个帖子中有过发言的用户。
- **基准测试**：对比了多种方法：
    - **监督微调（SFT-Init）**：论文RL训练的初始化点。
    - **Sim-RL**：使用**响应相似度奖励**进行RL训练（基于Wu et al., 2026的HumanLM方法），该奖励衡量生成响应与黄金标准响应的语义对齐程度。
    - **Logprob-RL**：使用**对数概率奖励**进行RL训练（基于Gandhi et al., 2026的方法），该奖励衡量模型对黄金标准响应的对数概率。
    - **强基线**：还对比了基线Qwen3-8B、更大的Qwen3.5-397B-A17B以及GPT-5模型。
- **评估指标**：
    - **LLM-as-a-Judge评估**：使用Sonnet 4.6作为评判器，从三个维度评估生成响应：
        - **图灵可区分性（Turing）**：评分模型响应与真实用户的不可区分性，这是主要指标。
        - **响应相似度（Similarity）**：模型响应与黄金标准响应的内容相似度。
        - **上下文与用户特异性（Specificity）**：响应是否紧密针对当前交互并与目标用户兼容。
    - **人类评估**：在Prolific平台上进行**二选一的图灵测试**。人类受试者根据用户历史，判断两个候选响应（一个真实，一个模型生成）中哪个是真实用户写的，以此评估模型的获胜率（Win Rate）。

### 6. 主要结论与发现

1.  **Turing-RL性能最优**：在两个领域、所有LLM评估和人类图灵测试指标上，Turing-RL训练的用户模拟器均**持续且显著地优于**使用响应相似度（Sim-RL）和对数概率（Logprob-RL）奖励训练的模型。
2.  **内容匹配 ≠ 不可区分性**：Sim-RL虽然能提升生成响应与黄金标准内容的相似度，但未能像Turing-RL那样提升模型的不可区分性。这表明优化“不可区分性”与优化“内容匹配”是两个不同的目标，而前者对于用户模拟更有效。
3.  **Turing-RL兼顾内容相关性**：尽管Turing-RL主要优化不可区分性，但它在内容相似度指标上也与Sim-RL表现相当，并未牺牲对用户原意的覆盖。
4.  **人机评判一致性**：人类评估和LLM（Sonnet 4.6）评估结论一致，都认为Turing-RL是最难与真实用户区分的模型，验证了这种训练方法的有效性以及LLM评估作为代理的合理性。
5.  **用户表示形式**：结合用户历史（`h`）和归纳人格（`ρ`）能取得较好效果。消融实验表明，仅使用归纳人格也能达到不错的图灵分数，说明人格捕捉到了风格和行为模式，但历史的加入能提升内容相似度。
